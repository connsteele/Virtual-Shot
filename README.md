# Virtual Shot (spike branch)

A throwaway spike for Virtual Shot, the planned browser tool for planning and rendering 3D shots. It rebuilds the
Black Page cold open on a scene document, a time core and three.js r186 (`WebGPURenderer` + TSL), and compares every
frame with the Black Page engine.

Start with [LEARNINGS.md](LEARNINGS.md): results, what the architecture plan got wrong, recommended doc changes, and
how to run it.
